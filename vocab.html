Import from Anki

New words get added and cards you've edited in Anki get updated. Nothing is ever deleted, so you can import one deck at a time.

Card format & how to export

How each card should look

Front
食べます · たべます
kanji form · kana
Back
to eat ← line 1: meaning
Example (optional label, ignored)
あさごはんをたべます。 ← Japanese sentence
I eat breakfast. ← its translation
  • Front: the word in kanji, then a middle dot, then the kana: 食べます · たべます. The dot can be · or the Japanese keyboard's ・ (with a space either side).
  • No kanji? Put a dash before the dot: — · どこ.
  • Emoji on the front are fine — they're ignored.
  • Back, line 1: the meaning in English.
  • Example sentences (optional): a Japanese line, with its English translation on the next line. You can add more than one pair. A line saying just "Example" is skipped, and bold or colours don't matter.
  • Press Enter between lines in the Anki editor so each is on its own line.
  • Note type Basic. The deck name becomes the filter tag here, e.g. Japanese::6. Genki 1::1. Lesson 1 shows as Genki 1 › Lesson 1.

Exporting from Anki

  1. In Anki, go to File → Export…
  2. Format: Notes in Plain Text (.txt) — not Anki Deck Package.
  3. Include: choose the vocab deck (or a single lesson deck).
  4. Tick Include HTML and media references, Include deck name and Include unique identifier. The identifier is what lets re-imports update words instead of duplicating them.
  5. Export, then choose that .txt file with the button above.
