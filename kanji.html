Import from Anki

In Anki: Browse → select the kanji deck → Notes → Export Notes → Notes in Plain Text, with Include HTML, Include deck name and Include unique identifier ticked. Cards should have just the kanji on the front, and romaji then meaning on the back. Only kanji that aren't already here get added.
