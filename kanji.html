Card format & how to export

How each card should look

Front
薬
Back
くすり ← line 1: reading in kana
Medicine ← line 2: meaning
  • Front: one single kanji (薬). No romaji, brackets like 「」 or other text.
  • Back, line 1: the reading in kana (くすり). Romaji like Kusuri still works — it gets converted to hiragana.
  • Back, line 2: the meaning in English.
  • Press Enter between the reading and the meaning in the Anki editor so they're on separate lines.
  • Words made of several kanji (大学, 入口) belong in your vocab deck — give each kanji in them its own card here instead (大, 学).
  • Note type Basic; any deck name works.

Exporting from Anki

  1. In Anki, go to File → Export…
  2. Format: Notes in Plain Text (.txt) — not Anki Deck Package.
  3. Include: choose your kanji deck.
  4. Tick Include HTML and media references, Include deck name and Include unique identifier.
  5. Export, then choose that .txt file with the button above.
